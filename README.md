🎲 Random Info App

A simple desktop application built with Python and PySide6 that shows random information based on the selected category.

✨ Features

- Choose a category from the list
- Get random information with one click
- Store information using SQLite
- Simple and user-friendly interface
- Different categories such as:
  - Funny
  - Motivational
  - Tech News
  - Movie
  - Game

🛠️ Technologies

- Python
- PySide6
- SQLite
- Qt Designer

📁 Project Files

- "main_window.ui" — User interface designed with Qt Designer
- "main_window.py" — Python version of the UI
- "sql.py" — Database operations
- "add_data.py" — Adds information to the database
- "random_info.py" — Main application
- "info_DB.db" — SQLite database
- "myvenv/" — Python virtual environment

▶️ How to Run

First, install the required package:

pip install PySide6

Then run the application:

python random_info.py

🎯 Purpose

This project was created as a practice project to learn Python, PySide6, GUI development, and SQLite databases.
